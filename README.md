# ЧМА 12 — СЕМЬЯ V5

V5 возвращает проект к идее «живого пиксельного дома»: вместо бегущих аватаров используется одна детально прорисованная сцена, где каждый из 11 участников сидит/стоит в своём месте.

## Что изменилось
- новый детализированный пиксельный интерьер `assets/house_scene.png`;
- 11 невидимых, но настоящих HTML-зон поверх персонажей: hover показывает ник, click открывает реплику;
- интерактивны не только персонажи, но и камин, бар, библиотека, общий стол, спальня и дверь во двор;
- профиль каждого участника сохраняется, включая 5 фраз;
- Rosynyan остаётся девушкой со свинкой;
- убраны WASD и бегущий player — теперь это статичная уютная сцена, как в RPG-хабе, где у каждого есть своё место;
- кнопка дня/ночи меняет освещение всей сцены.
